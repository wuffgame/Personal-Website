Hexus:

This is my first big project. The idea behind Hexus (E-Knowladge) was to create a programming language that would be accessible to everyone yet offer extensive capabilities, much like Python. My first programming language was Skript (yes, I consider it a programming language), and writing in it felt just like writing in English. I wanted a language that offered that same writing style but also allowed for programming advanced things, like scripts, programs, and even games. That's why I decided to create Hexus or another name E-Knowledge (name that came to me while I was washing up like always, though, of course, it was too long and hard to remember, which is how the name Hexus came about). Currently, Hexus is written in Python and its syntax isn't great, but I plan to rewrite it in C++ or C, improve the syntax, and yltimately transform the interpreter into a compiler. I still have a long way to go, but I hope to find the motivation to achieve my goal of creating a programming language that perfectly matches my vision.
